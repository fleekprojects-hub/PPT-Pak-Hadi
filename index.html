// PROBLEM RECOGNITION // THE COST OF PAPER-BASED OPNAME

Dari 249 Baris Kertas Manual ke Scanner Digital

Mengapa proses stock opname saat ini makan waktu berjam-jam dan rentan salah hitung.

❌ Proses Lama (Manual & Melelahkan) ± 3–4 Jam / Sesi
  • 1. Print File Excel Jubelio ke Kertas: Menghabiskan lembaran kertas berisi ratusan baris kode SKU kecil.
  • 2. Jalan Keliling Bawa Pulpen & Papan Ujian: Staff harus cari baris SKU satu per satu di kertas sambil hitung fisik baju di gantungan.
  • 3. Human Error Mata Lelah: SKU mirip (seperti K591BR vs K591BL) gampang salah centang atau terlewat.
  • 4. Input Ulang ke Laptop: Setelah selesai di kertas, harus diketik ulang satu per satu ke Excel untuk hitung selisihnya.
✅ Solusi Fleek KiiWii Mobile Scanner ± 15–20 Menit Selesai
  • 1. Upload File Excel Jubelio Sekali Klik: Drag-and-drop file stok (misal 249 SKU, 470 pcs). Database siap instan.
  • 2. Scan Mengalir Pakai Kamera HP: Arahkan kamera ke hangtag baju. Bunyi Beep! mengonfirmasi hitungan berjalan otomatis (+1).
  • 3. Normalisasi Cerdas Anti-Gagal: Tidak peka huruf besar-kecil (k407ar = K407AR) & abaikan nomor cetak label "330".
  • 4. Hasil Selisih Langsung Jadi: Merah bila stok hilang/kurang, Kuning bila lebih, Hijau bila klop. Sekali klik ekspor ke Excel.

💡 PENJELASAN TEKNIS CARA BACA BARCODE HANGTAG:
1. Angka "330" di Atas Garis:
Diabaikan otomatis. Itu nomor batch urutan cetak mesin label. Yang dibaca sensor kamera optik hanya garis hitam Code 128 yang isinya string K591BR.
2. Nambah (+) & Ngurangi (-):
Tiap scan sukses otomatis +1 pcs. Jika salah scan/ingin koreksi, cukup tap tombol [-] di tabel atau scan ulang dengan jeda anti-double.
3. Kalo Format Beda-Beda:
Normalisasi otomatis: huruf kecil (k407AR = K407AR), spasi, maupun kode tanpa warna (C122) dicocokkan otomatis ke database Excel Jubelio.

Arsitektur Ringan: 100% Web-Based (PWA)

Mengapa solusi ini 100% aman, cepat, dan tidak membebani tim KiiWii dengan instalasi aplikasi rumit.

Zero Installation (Web-Based)

Akses Langsung via Browser (PWA)

Staf tidak perlu download file APK asing yang bisa diblokir oleh keamanan Android, dan tidak butuh aplikasi chat pihak ketiga. Cukup buka link website di Google Chrome HP atau tambahkan ke layar utama (PWA) layaknya aplikasi resmi.

  • • Langsung dapat ikon di homescreen Android layaknya aplikasi native.
  • • Mendukung akses multi-staf secara bersamaan di lokasi rak berbeda.
  • • Akses kamera continuous berkecepatan tinggi (30 fps frame decoding).
Database Google Spreadsheet

Live Sync ke Google Sheets Privat

Seluruh data stok tersimpan langsung di Google Spreadsheet privat KiiWii (Google Drive Pak Hadi). Saat staf scan di toko, angka di Spreadsheet ter-update otomatis detik per detik.

  • • 100% Hak Milik Pak Hadi: Bisa dibuka dari laptop, HP, atau dibagikan ke tim admin toko.
  • • Multi-User Real-time: Beberapa staf bisa scan rak berbeda bersamaan tanpa data bentrok.
  • • Bebas Biaya Server: Zero hosting maintenance bulanan, tanpa database SQL rumit.

LOGIKA PENCOCOKAN BARCODE KIIWII (SAMPLE ANALYSIS RESULT):

1. Standard Code 128:
Decode persis kode SKU (contoh: K591BR). Angka batch cetak "330" di atas label diabaikan otomatis.
2. Normalisasi Huruf & Spasi:
Otomatis trim whitespace dan case-insensitive (k407AR dan K407ar dianggap sama persis).
3. SKU Spesial Tanpa Warna:
13 SKU model unik seperti C122 & R214 only langsung cocok 100% tanpa error format.
